# Software Architecture Projects

A collection of three projects demonstrating different software architectural styles.

## Projects

- **[broker/](broker/)** - Broker architectural pattern implementing a distributed authentication system with service discovery, registration, and invocation over TCP sockets
- **[mvc/](mvc/)** - Model-View-Controller pattern for a course registration desktop application with Observer-based view synchronization
- **[pipes-and-filters/](pipes-and-filters/)** - Pipes and Filters architecture implementing a KWIC (Key Word In Context) system with composable transformation stages
